# Frigoteca

Ricettario personale, tutto in locale (desktop e Android): le tue ricette, ricerca per nome e
per "cosa ho nel frigo". Stack: Tauri 2 + SvelteKit + SQLite.

Piano di lavoro: [PLAN.md](PLAN.md).

## Sviluppo

```sh
npm install
npm run tauri dev           # desktop
npm run tauri android dev   # Android (emulatore o dispositivo)
npm run check && npm test   # type check e test
```
